abstract: A method using a computing system is described that classifies each feedback text from a plurality of feedback texts into one or more categories. The method dynamically generates, using the plurality of feedback texts, a set of feedback text issues. The set of feedback text issues includes one or more issues associated with each feedback text from the plurality of feedback texts. The method dynamically generates, using the set of feedback text issues, one or more themes associated with the plurality of feedback texts. Each of the one or more themes is associated with a respective subset of feedback text issues from the set of feedback text issues. The method outputs a graphical user interface that includes one or more from the group consisting of at least one feedback text issue from the set of feedback text issues, and at least on theme from the one or more themes.
